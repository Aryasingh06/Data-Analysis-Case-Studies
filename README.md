# Data Analysis Case Studies
This repository contains multiple case studies demonstrating my learning and practical implementation of Python,
NumPy, Pandas, and Data Visualization libraries.

##  Case Studies Included

###  Bank Customer Transaction Management
- Python functions & dictionary
- Simulates basic banking operations

### Car Price Analysis (EDA)
- Data visualization using Seaborn & Matplotlib
- Insights on fuel type, pricing, and transmission

###  Insurance Data Transformation (NumPy)
- Data correction using NumPy
- Column swapping and aggregation

### Customer Feedback Analysis
- Mixed data handling (numerical + text)
- Statistical insights using NumPy

###  Patient Records Analysis (Pandas)
- Data cleaning & preprocessing
- Grouping, aggregation, and sorting

###  Tourism Data Analysis (Plotly)
- Interactive visualizations
- Seasonal and country-wise trends
##  Tech Stack
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Plotly
