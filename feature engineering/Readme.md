#  House Price Feature Engineering Case Study

## Overview
This project demonstrates how feature engineering can transform raw house listing data into more meaningful features
for analysis Using a real estate dataset new features were created to better represent property characteristics and 
market value.

## Dataset
* Records: 4,801
* Features: 17

### Key Columns
* PRICE
* BEDS
* BATH
* PROPERTYSQFT
* LOCALITY
* STATE
* BROKERTITLE

## Key Insights
* Price per square foot provides a more meaningful valuation metric than property price alone.
* Property size categories simplify property segmentation.
* Location popularity can be represented numerically through frequency encoding.
* Engineered features provide richer information than the original dataset.
* The transformed dataset is more suitable for future machine learning applications.

## Tools Used
* Python
* Pandas
* NumPy
* Jupyter Notebook

## Project Outcome
Successfully transformed raw house listing data into a feature-rich dataset by applying multiple feature 
engineering techniques, improving its analytical value and readiness for predictive modeling.
