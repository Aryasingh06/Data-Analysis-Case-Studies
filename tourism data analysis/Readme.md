#  Tourism Data Analysis (Plotly)

##  Objective
Analyze tourism trends using interactive visualizations.

## Tools Used
- Plotly
- Pandas

##  Analysis Performed
- Monthly tourist trends
- Country-wise analysis
- Travel cost vs bookings
- Seasonal variations

##  Key Insights
- Peak season: May to September
- Australia contributes highest tourists
- Summer is most expensive season

## Conclusion
Tourism trends are highly seasonal and influenced by travel cost.
