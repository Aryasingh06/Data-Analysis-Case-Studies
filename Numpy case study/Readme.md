## Insurance Data Transformation using NumPy

##  Objective
Fix incorrect data caused by column misplacement using NumPy operations.

## Concepts Used
- NumPy array manipulation
- Column swapping
- Data aggregation

##  Task Performed

- Swapped premium and claim amount
- Calculated total claim amount

##  Key Learning
- Efficient data handling using NumPy
- Importance of data accuracy in industry

## Real-World Relevance
Ensures correct financial reporting in insurance systems.
