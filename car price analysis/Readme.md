# Car Price Analysis
## Objective
Analyze used car dataset to identify pricing patterns and influencing factors.

##  Tools Used
- Pandas
- Seaborn
- Matplotlib

##  Analysis Performed
- Fuel type distribution
- Price distribution
- Price vs transmission
- Correlation analysis

##  Key Insights
- Diesel cars dominate listings
- Most cars fall under budget range (~5 lakh)
- Automatic cars have higher resale value
- Price slightly depends on year and usage

##  Conclusion
The analysis shows that affordability and fuel type significantly impact car pricing in the resale market.
