#  Bank Customer Transaction Management

##  Objective
To simulate a banking system using Python dictionaries and functions for managing customer data.

## Concepts Used
- Python Functions
- Dictionary (Key-Value Storage)

##  Features
- Add new customer
- Display customer details
- Deposit and withdraw money

##  Key Learning
- Efficient data storage using dictionaries
- Code reusability using functions
- Basic simulation of banking logic.
- 
##  Conclusion
This project mimics a small-scale banking system and helps in understanding how structured data is managed in real-world applications.
